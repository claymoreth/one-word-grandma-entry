A single word, the way a grandma would sum up artificial intelligence in one
text message: warm, honest, a little wide-eyed, and straight from the heart.
No explanation, no paragraph — just the one word she would send back.

[View the bounty on make.fun](https://make.fun/bounty/u-0xkianno-one-word-from-grandma-f04bed16)

## How it works

Run `python3 main.py` and it writes the entry word to `entry.txt` in the
output directory (`MAKEFUN_OUTPUT_DIR` when set, otherwise `output/` under
`MAKEFUN_BOT_DIR` or the current working directory).
